## 1. 下载扩展

1. 点击仓库右上方的 **Code**。
2. 点击 **Download ZIP**。
3. 将下载的 ZIP 完整解压到一个固定目录。
4. 确认解压后的目录中可以直接看到 `manifest.json`。

## 2. 导入浏览器

| 浏览器 | 扩展管理页面 |
| --- | --- |
| Google Chrome | `chrome://extensions/` |
| Microsoft Edge | `edge://extensions/` |

1. 在地址栏打开对应的扩展管理页面。
2. 开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择包含 `manifest.json` 的扩展目录。
5. 导入完成后，将 **Onlyfans Downloader** 固定到浏览器工具栏。

## 3. 开始使用

1. 在当前浏览器中登录 OnlyFans。
2. 打开或刷新 OnlyFans 页面。
3. 点击浏览器工具栏中的 **Onlyfans Downloader** 图标。
4. 选择创作者、Media Source、Media Type 和输出文件夹。
5. 点击开始按钮创建下载任务。

## 4. 更新扩展

1. 下载并解压最新代码，覆盖原扩展目录。
2. 返回扩展管理页面。
3. 点击 **Onlyfans Downloader** 卡片上的刷新按钮。
4. 刷新已打开的 OnlyFans 页面。
